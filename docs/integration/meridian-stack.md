# External toolset support removed

The September 20 user decisions remove Meridian-MCP, Aphelion Content Tools and
Rift build tooling from AphelionDMM. Their commands, adapters, integration
manifests and external acceptance gates are no longer supported.

Map fidelity uses AphelionDMM's native DME/DMM/TGM parser, operation model and
validated atomic saves. Meridian-Rift's DME and IceBox remain user-selected input
fixtures; no MCP server or game build tool is required to use those files.

Earlier integration plans and verification reports are historical evidence.
Their unrun or failed MCP checks are superseded, not remaining blockers.
